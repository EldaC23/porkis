# Porkis Burger · Menú interactivo (demo)

Abrir `index.html` en cualquier navegador (celular o PC). Sin dependencias.

- 25 productos de ejemplo en 5 categorías (editar el array `PRODUCTS`).
- Personalización de burgers (extras y aclaraciones), buscador y carrito.
- El pedido se envía por WhatsApp: cambiar `WHATSAPP` por el número real del local.
- Texto comercial para el dueño: ver `OFERTA.md`.
